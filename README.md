# Aashish — Freelancer Portfolio

A static portfolio website for a freelance video editor.

## Customize
1. Edit `index.html` and replace:
   - `YOUR-EMAIL@example.com`
   - `YOUR_USERNAME`
   - sample prices and text
2. Put your own licensed/original videos/images inside `assets/`.
3. Replace the placeholder project cards with your real work.

## Publish
This is a static HTML/CSS/JS site, so it can be hosted on GitHub Pages or another static host.
