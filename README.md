# NEXORA V2 — Freelance Video Editing Website

Upload the contents of this folder to the root of your GitHub repository.

## Before publishing
Edit `index.html` and replace:
- `YOUR_WHATSAPP_NUMBER` with your WhatsApp number including country code, e.g. 91XXXXXXXXXX
- `YOUR_INSTAGRAM_USERNAME` with your Instagram username
- `YOUR-EMAIL@example.com` with your email
- sample pricing
- placeholder project text

For real portfolio videos, use your own original or properly licensed footage. The current project cards are placeholders so the site works without extra media files.
